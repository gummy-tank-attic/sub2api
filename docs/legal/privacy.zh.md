# 隐私政策 (Privacy Policy)

**最后更新日期：** 2026年10月6日  
**生效日期：** 2026年10月6日  

**HELIX TECH LLC**（以下简称“公司”、“我们”或“本公司”）拥有并运营 **FXVIA** 平台（以下简称“本平台”）。我们高度重视您的隐私权利与个人数据安全，并严格遵循全球通行的隐私合规标准，包括《通用数据保护条例》（GDPR）和《加利福尼亚州消费者隐私法》（CCPA）。

本《隐私政策》（以下简称“本政策”）详细说明我们在您访问和使用 FXVIA 服务时如何收集、使用、存储及保护您的信息。

---

## 1. 我们收集的信息
为了向您提供高可用的 API 网关基础设施及满足合规审计要求，我们收集以下必要数据：
- **账户注册信息：** 当您注册账户时提供的电子邮箱地址、用户名、密码哈希值以及必要的账单联系信息。
- **系统运行与审计数据：** 包含 API 请求时间戳、所调用的模型端点、HTTP 状态码、Token 消耗量、错误日志以及用于防御网络攻击和安全审计的访问 IP 地址。
- **支付凭据记录：** 由合规的第三方支付网关处理的交易流水号与结算确认记录。我们在自己的服务器上**绝不存储**您的完整原始信用卡卡号或支付卡敏感安全码（CVV）。
- **零提示词留存政策（Zero Prompt Retention）：** 所有经由 FXVIA 网关路由与转发的用户请求 Prompt 和模型输出内容，仅在服务器内存中进行流式处理传输，**绝不落盘存储，绝不归档留存，且绝不用于任何 AI 模型的训练或微调**。

## 2. 信息的使用目的
我们收集的数据仅在严格合法的限度内用于以下目的：
1. 提供、维护、优化与保障 FXVIA API 路由网关的正常运行；
2. 准确核算并处理按量计费与账户余额扣减；
3. 防范欺诈、滥用调用、DDoS 攻击及执行平台的可接受使用政策；
4. 履行适用的法定合规义务、监管披露及反洗钱（AML）要求。
我们**绝不出售**您的任何个人数据，亦不向任何第三方数据中间商披露您的个人信息。

## 3. 数据安全与保护措施
我们实施行业领先的行政、技术与物理安全防范机制来保护您的数据资产：
- 全平台数据通信均实施端到端 TLS 1.3 高强度加密传输；
- 遵循最小特权原则实施严格的内部访问权限隔离；
- 部署全天候自动化异常流量监控与防篡改审计机制。

## 4. 您的数据权利
根据您所在司法管辖区的隐私法律法规，您享有以下法定数据权利：
- 查阅及获取我们所持有的关于您的个人数据副本；
- 更正或更新不准确的个人信息；
- 要求注销账户并删除您的相关个人数据；
- 限制或拒绝特定形式的数据处理。
如需行使上述任何权利，请通过本政策列明的联系邮箱向我们提出书面申请。
