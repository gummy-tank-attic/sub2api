# 退款与取消政策 (Refund & Cancellation Policy)

**最后更新日期：** 2026年10月6日  
**生效日期：** 2026年10月6日  

本《退款与取消政策》（以下简称“本政策”）适用于 **HELIX TECH LLC**（以下简称“公司”或“我们”）运营的 **FXVIA** 开发者平台（以下简称“本平台”）上的所有账户充值、数字服务与付费订阅。

---

## 1. 服务性质与计费模式
FXVIA 提供企业级 AI API 路由网关与数字化基础设施服务。由于底层计算资源与上游模型调度具有即时消耗性：
- **已消耗额度（不可退款）：** 任何已成功发起并完成调用的 API 请求、Token 消耗费用及已使用的计算配额，属于即时交付的数字化资源，**严格不予退款**。
- **未消耗充值余额（可退款）：** 用户在账户充值之日起 **十四（14）个自然日内**，可就账户内**尚未使用且有效的充值余额**申请全额原路退还。超出十四个自然日的充值余额将保留在您的账户余额中供持续使用，通常不再支持退款申请。

## 2. 退款申请流程
如需就尚未使用的有效充值余额申请退款，请按以下步骤操作：
1. **提交申请：** 使用您的账户注册邮箱发送邮件至 **contact@fixvia.com**，邮件主题请注明：`退款申请 - [您的注册邮箱]`。
2. **提供凭证：** 邮件中请附带充值订单编号、交易流水凭证及申请原因。
3. **审核与处理：** 我们的支持与财务团队将在收到申请后的 **三（3）个工作日内** 完成核对。审核通过后，退款将全额原路退回至您的原始支付渠道。退款到账时间通常为 5 至 10 个工作日，具体取决于您所使用支付渠道或发卡银行的处理周期。

## 3. 账户注销与服务终止
用户可随时在控制台注销账户或联系客服终止服务。账户注销时，若账户内存在符合第 1 条规定的未消耗有效充值余额，可在账户关闭前按照退款流程申请退还。

## 4. 账单疑问与争议解决
如果您对账单明细、扣费记录有任何疑问，或认为可能存在计费异常，**请在发起银行拒付（Chargeback）或银行调单前，优先联系官方支持团队进行核实与友好调解**。我们承诺以专业、高效的态度妥善解决您的合理诉求：
- **运营主体：** HELIX TECH LLC
- **客服与退款邮箱：** contact@fixvia.com
