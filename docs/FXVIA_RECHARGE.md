# FXVIA 按人民币订单充值

本地实现，尚未启用生产配置。目标为人民币订单金额与站内额度数值一致；BEpusdt 按建单时同步汇率计算应付币数。

## 实例配置

易支付实例配置新增可选字符串键 `bepusdtCNYRecharge`。仅服务端配置值为 `"true"` 时启用，默认关闭。后续通过现有管理员支付实例更新接口合并此配置；无需新增数据库字段或在公共建单请求中传汇率。

- 仅余额充值发送 `fiat=CNY` 和 `rate=~1`，参数参与签名。
- `~1` 使用 BEpusdt 同步的原始 CNY/币汇率，而非共享网关可能固定为 1 的实际费率。它不表示固定 1:1 收币。
- 仅支持跳转收银台（`payment_mode=popup`）；当前部署的 BEpusdt 不提供 `mapi.php`，开启本功能后使用其他模式将拒绝建单。
- 只允许配置映射后的 `usdt.trc20`、`usdt.bep20`、`usdc.base`；其他方式拒绝建单，新增通道需先验证再扩展。
- 订阅不启用该参数；未启用此配置的实例保持原行为。
- 启用实例的余额充值要求 `balance_recharge_multiplier=1`，否则在持久化订单和请求网关前拒绝建单，防止二次换算。
- 有进行中订单时，实例配置的开关变更受现有待付款检查约束。

例如订单 ¥67、汇率 6.7 元/USDT：应付约 10 USDT，到账 $67 站内额度。以付款页实际币数为准，网关精度和同地址金额匹配可能产生微小调整。模型计费倍率不参与充值报价。

## 切换验收

1. 本地测试通过，前端可见修改先预览确认；按运维规范备份和发布固定 digest 镜像。
2. 暂停余额充值，等待在途建单完成，重新核对本站和网关的待付款订单；处理或等待旧单终止后切换。不要单独改倍率后开放。
3. 对 BEpusdt 实例启用 `bepusdtCNYRecharge="true"`，将本站充值倍率设为 1，确认配置加载后受控验收。
4. 三种通道核对 `fiat`、订单法币金额、网关锁定汇率、应付币数和站内到账额度；验证一笔真实小额付款、回调幂等及后续模型扣费。
5. 检查 BEpusdt 汇率更新时间、收银台显示、切换币链或重新报价行为。共享 Nginx 的 CNY→USD 替换必须确保不误导 FXVIA 用户。未完成这些核验前，不宣称已完成生产切换。

此实现不提供网关汇率新鲜度校验，不更改 BEpusdt 的全局参数或页面，不重算历史订单/余额。上线前仍需验证运行版本在换币链、过期订单和重试时保留单笔报价策略，禁止用假付款回调代替真实付款验收。

回滚同样先暂停并清理在途订单，再恢复旧镜像和配置组合。退款仍按现有开关和订单金额逻辑处理，不因本次适配开启退款；有实际退款需求时另行核对币数与原订单报价。

## 本地与网关核验记录（2026-10-08）

- 网关版本 v1.24.2-4d88040；通过 VPS 本机 Nginx 和风控代理请求实际网关。三种通道的 ¥6.70 测试订单均使用 CNY、汇率 6.7、应付币数 1；不传新参数的对照订单仍为汇率 1、币数 6.7。
- EasyPay 订单返回 `reselect=false`，尝试换通道被拒绝，持久化报价未变。
- 此次产生的 5 个未付款测试订单已通过官方取消接口清理，未付款、未伪造回调，核对的共享配置保持不变。
- 公网最初返回 403，后定位为 Cloudflare 对 Python 默认 User-Agent 的拦截（1010）。使用浏览器标识重新验证，三种通道及旧参数对照的公网签名建单、查询和取消均通过；无需修改共享防护配置。
- 另以真实浏览器打开一笔公网 GET 建单的收银台，显示 `1 USDT`、`6.7 CNY`、Bsc 网络。共享 Nginx 的 HTML 替换未误改动态币种。该笔订单也已取消；本轮共清理 5 笔未付款测试订单。
- 前端金额输入符号改为跟随支付币种；人民币订单即使倍率为 1 也显示美元站内到账额度，避免混淆支付金额和额度。33 项相关前端测试通过。
- 尚未验证真实付款、风控放行后的回调转发和最终到账；公网报价成功不能替代这项验收。
- 原始汇率来自 BEpusdt 的 CoinGecko 同步任务，当前同步间隔为 3600 秒；在建单时报价并锁定，不是付款瞬间重新查询。
- 本地页面预览使用模拟账户与充值倍率 1，截图位于运维工作区 `output/playwright/fxvia-recharge-local.png`。生产充值倍率仍为 7，尚未启用新功能或部署。
